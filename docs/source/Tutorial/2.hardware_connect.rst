2. Hardware Connection
=========================

This chapter will guide you through the hardware assembly of the XiaoZhi AIoT Smart Control System, including connecting the ESP32-S3 main controller with 8 functional modules.

.. warning:: 
   Before starting assembly, ensure all power sources are disconnected to avoid wiring operations while powered on.

GPIO Pin Assignment
----------------------

The following shows the pin correspondence between each module and ESP32-S3:

     - Digital Signal
     - GPIO17

Assembly Steps
-----------------

**Step 1: Main Controller Installation**

1. Insert the ESP32-S3 development board, audio board, and screen into the corresponding areas of the AI Chatbot IoT Shield
2. Ensure pins are aligned to avoid bending damage
3. Insert the AI Chatbot IoT Shield into the breadboard

**Step 2: Power Connection**

1. Connect the included 12V power adapter to the AI Chatbot IoT Shield

**Step 3: Sensor Module Connection**

1. Connect the DHT11 sensor according to the pin assignment table
2. Connect the rain sensor and soil sensor
3. Check connection stability

**Step 4: Actuator Module Connection**

1. Connect the RGB LED module
2. Install the servo and WS2812 LED strip
3. Connect the fan and relay modules

Connection Verification
--------------------------

**Basic Checklist**

□ ESP32-S3 development board installed in place
□ All Dupont wires securely connected
□ Signal wires connected according to wiring table
□ USB cable connected to computer, ready for firmware upload

**Function Testing**

1. **Power-on Test**: After connecting USB, the development board indicator light should illuminate
2. **Voice Test**: Say "Hi ESP" to wake the device and listen for response
3. **LED Test**: Say "Hi ESP, turn on LED" to test lighting
4. **Sensor Test**: Say "Hi ESP, check temperature" to get data

.. tip:: 
   It is recommended to test each function sequentially to ensure each module works properly.
